# 📞 Phone Bill Calculator with Price Plans

A Node.js + Express web app that allows users to define custom price plans for calls and SMS, and calculate the total phone bill based on selected usage. Powered by SQLite and a dynamic frontend using Alpine.js.

## 📌 Features

- Create custom price plans with different rates for calls and SMS.
- View, update, or delete existing plans.
- Enter usage logs (e.g. `call, sms, call`) and calculate the total bill using a selected price plan.
- Interactive UI using Alpine.js and HTML.

## 🛠️ Tech Stack

- **Backend**: Node.js, Express.js
- **Database**: SQLite
- **Frontend**: HTML, CSS, Alpine.js
- **API Interaction**: Axios (optional)
